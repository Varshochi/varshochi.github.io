Privacy Policy

Version 1.0 · Last updated 16 August 2026

What Site Intel does

Site Intel analyzes the website you are actively viewing to provide website intelligence including SEO, technology, host and DNS information, security-header signals, robots and sitemap information, tracker detection, speed measurements, and link-health checks.

Data processed locally

Page content and page metadata used for most SEO and technology checks are processed locally in your browser. Site Intel does not operate an advertising profile and does not sell browsing activity or personal data.

Public lookup services

To provide public infrastructure information, Site Intel may send a website hostname or its public IP address to third-party services used for DNS resolution, RDAP registration and network data, IP geolocation, and graphical country flags. These requests are used only to provide the Site Intel feature you are viewing.

Google PageSpeed

Google PageSpeed and Lighthouse are optional. The current page URL is sent to Google's PageSpeed Insights service only when you explicitly press the Run test button. A PageSpeed API key, if you choose to provide one, is stored locally in your Chrome profile.

Compare and broken-link checks

When you explicitly use Compare, Site Intel contacts the website you entered. If that site blocks a direct page fetch, Site Intel falls back to limited public domain, DNS, crawl, and security signals. When you explicitly run the Broken Link Check, Site Intel contacts a limited set of links found on the current page to read their HTTP response status.

Local storage

Site Intel may store recent scan summaries, watchlist entries, settings, and an optional PageSpeed API key using Chrome extension storage in your Chrome profile. Site Intel does not operate a developer-controlled analytics backend for this information.

Data sharing and advertising

Site Intel does not sell user data and does not use or transfer user data for personalized, retargeted, or interest-based advertising. Data is transmitted to external services only where necessary to deliver the user-facing lookup or test requested by the extension.

Security

External requests made by Site Intel use HTTPS where supported by the relevant service.

Chrome Web Store Limited Use

Site Intel's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Information accessed through Chrome permissions is used only to provide or improve Site Intel's user-facing website-analysis functionality.
